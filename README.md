# Automatic Teller Machine simulator (ATM).

This project is a practice using python, based on the concepts learned in the book PYTHON crash course(third edition).

The objective is to simulate basic operations for an ATM using only the terminal.

## Project structure

* 'main.py' - is the main entry of the program (in development).
* 'frontend.py' - user interface for the menu using the terminal (in develoment).
* 'active_users.py' - a simulated database using nested dictionaries (completed for now).
* 'user_verification.py' - autentication logic for the username an pin number (in development).
* 'operations.py' - functions for: balance, withdrawal, deposits and transactional history (in development).

## Program flow

- [] log in and user verification.
- [] balance inquiry.
- [] funds deposits.
- [] withdrawal.
- [] transactional history for the sesion.
